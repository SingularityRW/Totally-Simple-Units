### How to Install

1. Grab the latest `.rwmod` file from **[Releases](https://github.com/SingularityRW/Totally-Simple-Units/releases/latest)**. Don't extract or mess with the file.
2. Put it in your `rustedWarfare/units/` folder (or import it from the in-game **Mods** menu).
3. Turn it on in-game and restart if needed.
